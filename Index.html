Bienvenidos

En esta presentación voy a hablar sobre qué es Vue, cómo instalarlo, cómo crear un proyecto y qué son los componentes.

Usá el menú de arriba para cambiar de diapositiva.

¿Qué es un framework?

Un framework es una estructura de trabajo que contiene herramientas, funciones y reglas que ayudan a crear aplicaciones de forma más rápida y organizada, como por ejemplo JavaScript.

  • Permite reutilizar código y se puede integrar poco a poco en proyectos existentes.
  • Organiza la interfaz en partes pequeñas, independientes y reutilizables.
  • Permite sincronizar los datos de la aplicación con lo que ve el usuario.

¿Qué es Vue?

Vue es un framework progresivo de JavaScript utilizado para crear interfaces de usuario y aplicaciones web de forma sencilla, rápida y flexible.

  • Componentes: divide la página en partes reutilizables que permiten organizar el código.
  • Reactividad: si cambia un dato, la pantalla se actualiza sola.
  • Gran rendimiento: permite crear interfaces rápidas y eficientes.

Instalar Node.js y Vue

1. Instalar Node.js: entrar a nodejs.org y descargar el programa. También instala npm, que sirve para instalar herramientas y paquetes.

2. Comprobar la instalación: abrir la terminal y escribir:

  • node -v: muestra la versión de Node.js.
  • npm -v: muestra la versión de npm.

Si aparecen números de versión, significa que están instalados correctamente.

3. Instalar Vue: abrir la terminal dentro del proyecto y escribir:

  • npm install vue: instala Vue en el proyecto.

Listo, ya tenés los pasos básicos para empezar a trabajar con Vue.

Crear y ejecutar un proyecto

Para crear y ejecutar un proyecto de Vue, seguí estos pasos:

  • Crear el proyecto: escribir npm create vue@latest en la terminal.
  • Entrar a la carpeta: usar cd nombre-del-proyecto.
  • Instalar las dependencias: escribir npm install.
  • Ejecutar el proyecto: escribir npm run dev.

Después de ejecutar el último comando, la terminal muestra la dirección local para abrir el proyecto en el navegador.

¿Cómo funciona Vue?

Vue permite crear páginas web que reaccionan a los cambios que hace el usuario.

  • Datos: contienen la información que muestra la página.
  • Interfaz: es la parte de la página que ve el usuario.
  • Actualización automática: si cambia un dato, Vue actualiza la pantalla sin recargar toda la página.
  • Interacción: permite que la página responda a acciones como hacer clic en un botón o escribir en un campo.

Componentes

Los componentes son partes de una página web que sirven para organizar mejor el contenido y reutilizarlo.

  • Encabezado: muestra el título de la página.
  • Menú: permite ir a las distintas secciones.
  • Contenido: muestra la información principal.
  • Pie de página: muestra información al final de la página.

En Vue, cada una de estas partes se puede crear por separado y después unirlas para formar una página completa.
