Bienvenidos

En esta presentación voy a hablar sobre qué es Vue, cómo instalarlo, cómo crear un proyecto y qué son los componentes.

¿Qué es un framework?

Un framework es una estructura de trabajo que contiene herramientas, funciones y reglas que ayudan a crear aplicaciones de forma más rápida y organizada, Como por ejemplo Java Script.

  • Permite reutilizar código y Puedes integrarlo poco a poco en proyectos que ya existen.
  • Tiene un sistema de componentes ordenados que permite dividir la interfaz en piezas pequeñas, independientes y reutilizables.
  • Los datos de la aplicación se sincronizan de forma automática con lo que ve el usuario en la pantalla.

¿Qué es Vue?

Vue es un framework progresivo de JavaScript utilizado para crear interfaces de usuario y aplicaciones web de forma sencilla, rápida y flexible.

  • Componentes: divide la página en partes reutilizables que te permite organizar el codigo.
  • Reactividad: si cambia un dato, la pantalla se actualiza sola(mantiene sincronizado lo que el usuario ve en pantalla con los datos de la aplicacion).
  • Gran rendimiento: permite crear interfaces rápidas y eficientes.

Instalar Node.js y Vue

1. Instalar Node.js: entrar a nodejs.org y descargar el programa. Este también instala npm, que sirve para instalar herramientas y paquetes.

2. Comprobar la instalación: abrir la terminal y escribir estos comandos:

node -v
npm -v

Si aparecen números de versión, significa que están instalados correctamente.

3. Instalar Vue: Vue se puede agregar a un proyecto existente escribiendo este comando en la terminal:

npm install vue

Listo, Ya tenés los pasos básicos para empezar a trabajar con Vue.

Crear y ejecutar un proyecto

1. Crear el proyecto:

npm create vue@latest

2. Entrar a la carpeta:

cd nombre-del-proyecto

3. Instalar las dependencias:

npm install

4. Ejecutar el proyecto:

npm run dev

¿Cómo funciona Vue?

Vue permite crear páginas web que reaccionan a los cambios que hace el usuario.

  • Datos: contienen la información que muestra la página.
  • Interfaz: es la parte de la página que ve el usuario.
  • Actualización automática: si cambia un dato, Vue actualiza la pantalla sin tener que recargar toda la página.
  • Interacción: permite que la página responda a acciones como hacer clic en un botón o escribir en un campo.

Componentes

Los componentes son partes de una página web que sirven para organizar mejor el contenido y reutilizarlo.

  • Encabezado: muestra el título de la página.
  • Menú: permite ir a las distintas secciones.
  • Contenido: muestra la información principal.
  • Pie de página: muestra información al final de la página.

En Vue, cada una de estas partes se puede crear por separado y después unirlas para formar una página completa.
